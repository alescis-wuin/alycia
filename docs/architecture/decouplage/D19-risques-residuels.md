## Données et retour arrière

La branche conserve les migrations de develop. Aucune migration nouvelle ni déplacement de données n’a été appliqué. Les essais PostgreSQL ont créé des bases temporaires. Pour retrouver l’état d’une phase sans toucher au checkout courant, utiliser `git worktree add --detach ../alycia-verification <SHA-publication>` avec le SHA du rapport. Le retour au code de develop suit la même commande avec le SHA D00 initial. Le traitement historique des originaux après un résultat de commit incertain demeure couvert par les tests de fork.
