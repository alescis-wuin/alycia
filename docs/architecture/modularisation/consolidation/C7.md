## Reproduire

Depuis un checkout existant, sous Bash ou fish :

```sh
git fetch origin
git switch refactor/alycia-consolidation-modularisation-20261121
git pull --ff-only
dotnet build Alycia.slnx
env -u ALYCIA_CHAT_TEST_CONNECTION bash scripts/check-context-v2.sh --pgvector
```

La dernière commande nécessite Docker et crée PostgreSQL/pgvector avec un mot de passe éphémère. Elle lance la garde, la compilation, le lint, les deux vérifications EF, les tests .NET, Python, HTTP et l’évaluation hors ligne. Pour employer un serveur de test existant avec le rôle CREATEDB, fournir `ALYCIA_CHAT_TEST_CONNECTION` dans l’environnement et lancer `bash scripts/check-context-v2.sh --pgvector`. Cette seconde voie a été utilisée pour cette recette, dans un cluster temporaire avec authentification SCRAM. Les sorties TRX sont dans `artifacts/tests/` et le JSON hors ligne dans le sous-dossier annoncé de `artifacts/evaluation/`.

Pour comparer le JSON au point de départ, exécuter le bloc de [recette](../recette.md) avec `ALYCIA_COMPARISON_BASE=65494a6a42b6b4a5e84b056eb6cb1d3c3afa9657` dans l’environnement Bash. L’évaluation conserve l’ordre de toutes les listes et retire exactement les quatre champs de ressources documentés.

Image seule, sur une machine disposant de Docker et de curl :

```bash
docker build -t alycia:consolidation .
(
container=$(docker run --rm -d -p 127.0.0.1::8080 alycia:consolidation)
trap 'docker stop "$container" >/dev/null' EXIT
binding=$(docker port "$container" 8080/tcp)
curl --fail --retry 15 --retry-connrefused --retry-delay 1 "http://$binding/healthz"
)
```

Pour lancer la démo locale, démarrer Ollama avec un modèle de chat installé. Exécuter `make demo-api` puis, dans un second terminal, `make demo-client`. Le lanceur crée le secret du dépôt si nécessaire. Exemple de campagne GPU après sélection des noms exacts renvoyés par `ollama list` :

```bash
ollama list
python3 scripts/evaluate-context.py run --model "$CHAT_MODEL" --embedding-model "$EMBEDDING_MODEL" \
  --retrieval hybrid --label consolidation --output artifacts/consolidation-gpu \
  --hardware "RTX 4070 Laptop 8 Go" --repeats 3
dotnet build benchmarks/Alycia.ContextBenchmarks
env ALYCIA_RERANK_DIRECTORY="$HORIZON_MODEL_DIR" python3 scripts/evaluate-context.py offline \
  --rerank --output artifacts/consolidation-onnx.json
```
