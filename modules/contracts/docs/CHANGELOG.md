# API publique

## 0.1.0

Première distribution locale des contrats de l’arbre signé fadd9aa4. Les identités CLR des types et la version d’assembly 1.0.0.0 sont conservées. Le numéro 0.1.0 désigne la première livraison par paquet. Le format JSON persistant garde son propre numéro de version.

Chaque modification de surface est comparée à la fixture de signatures du SDK épinglé et aux sérialisations. Documenter les ajouts compatibles dans une version mineure, les correctifs compatibles dans une version patch. Annoncer une suppression ou une incompatibilité, déprécier d’abord l’ancienne API et coordonner une nouvelle version majeure avec les consommateurs. Pour une même identité NuGet, le contenu est immuable.
