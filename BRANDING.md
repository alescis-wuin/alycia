# Branding

The public product name is **Alycia**.

The repository was originally bootstrapped with the misspelled technical identifier `Alicia`. Existing assembly names, namespaces, environment-variable prefixes, local-data paths and project directories may therefore still use `Alicia`/`ALICIA` internally.

During portfolio stabilization, public-facing product copy should use **Alycia**. Technical identifiers are intentionally kept stable until a dedicated migration can rename them atomically with build, test, documentation and data-compatibility updates.

Do not introduce new public-facing `Alicia` branding.
